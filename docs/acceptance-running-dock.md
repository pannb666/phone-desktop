## 一、问题与修复

| 现象 | 原因 | 修复 |
|---|---|---|
| 其他软件最大化时，底部（原任务栏位置）有一条空白 | 任务栏被隐藏，但 Windows 工作区仍是 2560×**1400**，最大化窗口只铺到 1400，剩下的 40px 露出覆盖层壁纸与 Dock 下沿 | 运行期把工作区扩到整屏（`SPI_SETWORKAREA`，**不广播** `WM_SETTINGCHANGE`，否则 Explorer 会按任务栏的 appbar 预留改回去）；退出时按任务栏实际位置恢复 |
| 最小化的软件找不回来 | 任务栏被隐藏，没有最小化按钮；Dock 只显示固定项 | Dock 增加"运行中的应用"区：图标 + 活跃高亮 + 最小化变淡；点击切换/恢复，右键菜单可切换、最小化、关闭 |

## 三、运行项的实现口径

- 枚举 `EnumWindows`，过滤：不可见、无标题、`WS_EX_TOOLWINDOW`、有 owner 的对话框、DWM cloaked（其它虚拟桌面）、本进程窗口、桌面壳层类名。
- 按 **exe 归组**（UWP 的 `ApplicationFrameHost` 按窗口标题归组），代表窗口优先取前台窗口。
- 每 900 ms 轮询一次（空闲 CPU 实测 **0.06%**，私有内存 81.6 MB），刷新时按 key 做增删改，不重建列表。
- 点击语义：最小化 → 恢复并激活；前台 → 最小化；其它 → 切到前台（`SetForegroundWindow` 失败时用 `AttachThreadInput` 兜底）。

## 四、取舍说明

工作区铺满后，**最大化窗口会盖住 Dock**（不再露出底部一条）。要看 Dock 就最小化窗口或 Win+Tab / Win+D；这与"普通窗口始终盖住覆盖层"的既有设计一致，也消除了原来那条无意义的空白。
